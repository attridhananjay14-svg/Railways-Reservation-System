# Railway Reservation System

A console-based Railway Reservation System developed using C++.

## Features

- Add and manage train records
- Add and manage passenger records
- Display, search, update, and delete records
- Book seats and cancel tickets
- Generate reservation reports
- Save and load records using file handling

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling
- Standard Template Library (STL)
